## Taxonomia reconstruida

La taxonomia observada en el repositorio usa estados como `Draft`, `Documented`, `Completed`, `Passed`, `Validated`, `Active`, `Recorded`, `Evidence Generated`, `Candidate Methodological Capability` y decisiones como `READY FOR CLOSURE`. Para esta reestructuracion no se propone una taxonomia global nueva; se usa una clasificacion documental local:

- `Canonical`: artefacto operativo o de gobernanza vigente.
- `Supporting`: evidencia, validacion, decision o registro necesario para entender la trazabilidad.
- `Historical`: documento conservado por trazabilidad historica, experimento, diagnostico, plan ejecutado o corpus.
