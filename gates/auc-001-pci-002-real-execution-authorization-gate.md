## 6. Blocking Conditions During Real Execution

The real execution must stop if:

- any MCP authentication, selector, allowlist or contract error appears;
- any required source cannot be validated or queried through MCP;
- the runtime-output write fails;
- `is_consumable = false`;
- any mandatory invariant is `FAIL`;
- the execution would write outside `outputs/auc-001/pci-002/2026-06-30/`;
- protected historical namespaces show changes.
